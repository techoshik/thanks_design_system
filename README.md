# Thanks Design System

Shared visual foundations, layout primitives, and reusable Flutter UI components
for Thanks applications.

## Local development

Add the package to an application with a path override:

```yaml
dependency_overrides:
  thanks_design_system:
    path: ../thanks_design_system
```

The package includes DM Sans as a variable font at
`assets/fonts/dm_sans/DMSans-VariableFont_opsz,wght.ttf`.
